PROJETO ONG — SOLIDARIEDADE VIVA

Estrutura:
- index.html: apresentação institucional
- projetos.html: campanhas de doação e voluntariado
- cadastro.html: formulário de engajamento
- css/style.css: estilos responsivos
- js/script.js: máscaras de CPF, telefone e CEP e validações complementares
- img/: imagens em JPG, WebP e SVG

Observação:
As imagens incluídas são artes originais criadas para este projeto acadêmico, portanto não dependem de direitos de terceiros.

Para testar:
1. Extraia a pasta.
2. Abra index.html em um navegador.
3. Navegue pelo menu.
4. Teste o formulário em cadastro.html.
