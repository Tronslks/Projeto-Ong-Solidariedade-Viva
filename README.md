# Projeto-Ong-Solidariedade-Viva
O projeto consiste no desenvolvimento de um site para a ONG Solidariedade Viva, utilizando HTML5, CSS3 e JavaScript. O código apresenta estrutura semântica, navegação entre páginas, formulário com validação e recursos de acessibilidade, aplicando conceitos de desenvolvimento web, usabilidade e organização de conteúdo.
